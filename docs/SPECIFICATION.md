# Jelly Bean Manager 仕様書

## 目的
Android 9以降からJelly Bean Digital Signage端末を管理する。通信を作る前にUIとローカル機能を整える。

## 画面
- ホーム: 端末・素材・プレイリスト数、クイックアクション
- 端末: 端末名、設置場所、状態、将来のペアリング
- コンテンツ: テキスト、画像、動画、天気、カレンダー
- プレイリスト: 表示内容、再生順、表示時間
- スケジュール: 曜日、開始・終了時刻、切り替えルール

## 現在
- Java / Android SDK
- SharedPreferencesにJSON形式でメタデータを保存
- 端末・素材・リスト・予定の追加、編集、削除
- 初回起動時のサンプルデータ
- GitHub ActionsでDebug APKをビルド

## 今後
- 素材ファイル選択とプレビュー
- プレイリスト項目の並べ替えと再生時間
- 曜日・時刻を指定するスケジュール編集
- QRペアリング、LAN内端末検出、認証
- メディア転送、オフライン再生同期、操作履歴

## セキュリティ
認証トークンをログに出さず、相手端末の認証とリクエスト検証を実装する。
